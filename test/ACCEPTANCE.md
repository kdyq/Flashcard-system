## 三、需你亲手做的验收(约 5 分钟)

1. **真实学习体验**:打开 http://localhost:5173 → 点「开始翻牌」翻几张卡(空格翻面、1-4 评分、Z 撤销),感受动效与间隔预览。
2. **AI 生成**:「AI」页 → 「填入示例笔记」→ 生成 → 勾选入库(Agnes 已配好,直接能用)。
3. **提醒授权**(你说开发完再测):设置页 → 打开「每天到点提醒我翻牌」→ 浏览器弹授权窗 → 允许;把提醒时间改成 1 分钟后等通知。
4. **手机宽度**:浏览器 F12 → 设备模拟 375px,过一遍仪表盘和学习页。
5. **FSRS 调参**:需要先累计 ≥400 条复习日志(日常使用两周左右),届时设置页「一键优化」→ 统计页对比未来负荷曲线变化。

## 四、已知边界(如实说明)

- **Node fetch IPv6 问题已修**:服务端启动强制 IPv4 优先(`dns.setDefaultResultOrder('ipv4first')`),否则本机访问 api.agnes-ai.cn 会因 IPv6 黑洞超时。
- **Agnes 响应偏慢**:实测连通 ~2-3s,生成 5 张 ~30-60s 属正常,工作台有 loading 态。
- **学习页撤销**采用"重新拉取队列"策略(Anki 同款行为),撤销后回到队首重新评分。
- **填空卡轮换**:同一张多挖空卡每次到期出一个挖空项,按复习次数轮换 c1→c2→c3。
- **自动备份**在服务端**启动时**触发当日首份(开发期 tsx 热重载不会重复备份,同日只一份)。
- Windows 下同时起多个 `npm run dev` 会端口混叠(SO_REUSEADDR);发现接口时好时坏时,结束全部 node 进程再起一次。
