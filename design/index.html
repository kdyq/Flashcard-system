FLASHCARD SYSTEM / UI DESIGN

三套前端设计方向

同样的功能（仪表盘 + 学习界面），三种视觉气质。请在浏览器中实际把玩后再选择，也可以混搭，比如「A 的布局 + C 的配色」。

每套都是可交互演示：顶部导航可切换「仪表盘 / 开始学习」；学习页支持点卡片或按空格翻面，按 1-4 评分（会落章 / 切卡），Z 撤销。示例卡循环 4 张。
A

A · 常青 Evergreen

清新学院风。侧边栏布局，翡翠绿主色，柔和圆角与阴影，进度环 + 热力图 + 负荷预测。最像一款现代学习应用。
 打开演示 B

B · 翻翻 FanFan

实体索引卡隐喻。手写体点缀，朱红印章元素，卡片堆叠、翻牌落章的物理动效。最有把玩感、最不像「生成的东西」。
 打开演示 C

C · 念念 NianNian

极简专注风。大留白、细线分隔、等宽数字、电光蓝单色点缀，动效快而克制。为长时间专注复习设计，最耐看。
 打开演示
三套均为浅色主题（按要求不做暗色）。技术栈预告：React + TypeScript + GSAP + Tailwind，正式开发时按所选方向落地。
